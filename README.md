# Тестирование Vim на совместимость с серверной операционной системой SELECTOS

Пункты задания 1-3 см. [Отчёт о тестировании](docs/report.pdf)

## Какие проверки реализованы

- Запуск и выход из vim

- Ввод и редактирование текста

- Сохранение и чтение файла

- Некорректные команды normal mode

## Какие инструменты используются

- vim

- vimscript

- make

## Как запустить проект локально

Установите зависимости проекта

```bash
    apt install git make
```

Загрузите проектный репозиторий и выполните тесты при помощи make

```bash
    git clone https://github.com/zafod42/Selectel-QA-test.git
    make
```
